# FastAPI Mental Health ML Backend

FastAPI service for student social media and mental health impact predictions.

## Setup & Running

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Server**:
   ```bash
   uvicorn main:app --reload --port 8000
   ```

3. **API Documentation**:
   Open `http://127.0.0.1:8000/docs` in your browser for Interactive Swagger UI.
